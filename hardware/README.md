# Hardware

- `enclosure/`: 3D-printed, waterproof, light, ventilated box. Several printable iterations.
- `boards/`: custom PCBs (KiCad), later: power distribution, sensors, possibly a carrier board for an RK3588 module.

Manufacturing: prototype with JLCPCB / PCBWay (PCB + assembly); shortlist Chinese ODMs for a full custom carrier board when the design is stable.
